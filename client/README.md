# desktop/ - client setup

Files in here turn any laptop / desktop into a control terminal for Claude
instances running on K12 (or any machine running `claude-mgr`).

This is the **client** side. You don't install claude-mgr or run instances
locally - the server stays on K12. From a client you just SSH in and attach
to existing tmux sessions.

## What lives here

| File | Role |
|---|---|
| `setup-client.sh` | One-shot client installer for Linux + macOS. |
| `claude-instances-<host>.cfg` | Auto-generated by `claude-mgr sync-ssh` on each server. One file per server. Don't edit. |
| `ssh-config.example` | Sample `~/.ssh/config` showing the Include line. |

## Linux / macOS client

```bash
curl -sSL https://raw.githubusercontent.com/Clinteastman/claudefarm/main/client/setup-client.sh | bash
```

This will:

1. Clone the repo to `~/github/claudefarm` (or where you choose)
2. Find or generate an SSH key
3. Add the `Include` line to `~/.ssh/config` (idempotent - won't duplicate)
4. Optionally `ssh-copy-id` your pubkey to K12 LXC 105
5. Test the connection
6. Print the SSH aliases you can now use (e.g. `ssh claude-k12-homelab`)

Re-run any time - it's idempotent.

## Windows client

There's no PowerShell installer yet. Manual steps:

1. Clone the repo:
   ```powershell
   git clone https://github.com/Clinteastman/claudefarm.git $env:USERPROFILE\github\k12-homelab
   ```
2. Add this line at the **top** of `%USERPROFILE%\.ssh\config` (above any
   `Host` blocks):
   ```
   Include ~/github/claudefarm/client/claude-instances-*.cfg
   ```
3. Copy your pubkey (`%USERPROFILE%\.ssh\id_ed25519.pub`) into
   `/root/.ssh/authorized_keys` on K12.
4. Test: `ssh claude-k12-homelab`

## Refreshing aliases

When K12 spins up or removes instances, the alias file in this directory is
re-generated and committed automatically. Run `git pull` in your local clone
on each client to pick up the new aliases.

If you've added another machine running `claude-mgr` (e.g. a Pi, another
LXC), its aliases will appear as `claude-instances-<hostname>.cfg` and the
glob Include picks them up automatically.
